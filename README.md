# [Youtube] Video Memory

记住每个 YouTube 视频的播放进度，下次打开时自动从上次的位置继续播放。

**[点此安装](https://raw.githubusercontent.com/0-V-linuxdo/Youtube-Memory/main/userscript/%5BYoutube%5D%20Video%20Memory.user.js)**：装好后脚本管理器会自动检查更新。从 v1.x 升级时，已有记录和设置无需迁移。

## 功能

- **自动保存 / 恢复进度**：等待播放器就绪、自动避开广告；恢复后会多次确认位置，被 YouTube 拉回时会重新跳转。
- **时间戳链接冲突提示**：链接里带 `t=` 且与已保存进度相差较大时，弹窗让你选择从哪里播放。
- **播放器徽标**：在播放器上显示「上次保存」时间和同步状态。
- **提示**：恢复进度、保存失败、云同步出错等在页面底部弹出提示（徽标被隐藏时也看得到）。
- **多标签页同步**：多个 YouTube 标签页之间实时同步记录、设置和界面语言；暂停的旧标签页不会覆盖另一个标签页的新进度。
- **一切皆插件（Void++ 风格）**：点播放器里的齿轮弹出插件菜单，直接打开某个插件的设置子弹窗，或选「全部插件」打开设置窗口（只有插件页：收藏 / 置顶 / 开关 / 设置）。记录列表（搜索筛选、笔记、链接、字幕，删除需确认）、存储后端切换与迁移、JSON 导入导出、界面语言等都在各自插件的设置子弹窗里。
- **启动时整理记录**：删除损坏的记录，补全缺失字段。
- 中英双语界面，单色配色，跟随系统深色 / 浅色主题。

## 插件

| 插件 | 说明 |
| --- | --- |
| 进度引擎（必需） | 保存与恢复播放进度 |
| 播放器徽标（必需） | 播放器上的状态徽标、齿轮按钮与续播选择弹窗 |
| 设置窗口（必需） | 设置窗口（插件页）、插件设置子弹窗、齿轮插件菜单；界面语言、是否先显示插件菜单 |
| 存储（必需） | 存储后端切换与迁移、JSON 导出 / 导入 |
| 记录 | 已保存视频列表（大号子弹窗） |
| 插件菜单 | 选择齿轮菜单里列出哪些插件 |
| 徽标开关 | 一键隐藏 / 显示播放器徽标 |
| 字幕 | 字幕接口设置；在记录卡片上获取、复制字幕（依赖「记录」） |
| 提示 | 页面底部的提示，可设置停留时间 |
| 多标签页同步 | 标签页之间同步记录、设置与进度 |
| 云同步 | 通过 Google Drive 在多台设备间同步记录 |

非必需插件可在设置窗口的「插件」页中启用或停用，停用后立即移除其添加的所有内容（关闭「记录」不影响进度的保存与恢复）。打开一个插件会同时打开它依赖的插件，关闭一个插件会同时关闭依赖它的插件。

## 安装

1. 安装 Tampermonkey（或 Violentmonkey 等）脚本管理器。
2. 打开[安装链接](https://raw.githubusercontent.com/0-V-linuxdo/Youtube-Memory/main/userscript/%5BYoutube%5D%20Video%20Memory.user.js)，按提示安装。脚本带有 `@updateURL`，之后会自动更新。

## 构建

需要 [Bun](https://bun.sh)。

```sh
bun run build.ts        # 生成 userscript/*.user.js 与 *.meta.js（--dev 为开发构建）
npx tsc --noEmit        # 类型检查
NODE_PATH=$(npm root -g) node tests/acceptance.mjs   # 验收测试（需全局 Playwright）
```

源码结构：`src/api`（插件 API 与界面部件 `ui.ts` / `dialogs.ts`）、`src/utils`（工具）、`src/plugins/_core`（核心插件）、`src/plugins/*`（可选插件）。新增插件只需在 `src/plugins/` 下新建目录，构建时会自动注册。
